# TEAM01 v9 — 출발 우측 연석 유지 / 1랩 실시간 탐색 / 2랩 조건부 증속

기존 `team01_race`에 덮어씁니다. **트랙 SDF/JSON/CSV 좌표를 주행 알고리즘에 읽어들이지 않습니다.**
차량 스폰 좌표는 독립 실행기의 그리드 시작 위치 지정용입니다. 도로 형상 정보로 사용하지 않습니다.

## 주행 정책

1. RGB 카메라의 빨간 신호 최소 4개 점등→전체 소등 확인 후 출발합니다. 운영자 `/race/start/team01=true` 허가도 유지합니다.
2. **첫 3초간** (차량이 실제로 움직이는 시간 누적) 센서로 관측한 **오른쪽 연석까지의 초기 간격**을 유지하도록 조향합니다. 조향 명령은 좌우 **3° 이하**로 제한합니다. 양측 연석/도로 안전 경로를 확인할 수 없으면 **멈춥니다**. 우측 연석이 위험하게 가까워지면 기존 안전 정지 로직이 우선합니다.
3. 3초 이후 연속 6번 확인된 도로 좌우 경계와 최소 0.65m 이동을 만족하면 `CENTER`로 전환합니다. 약 2초 동안 초기 우측 간격 경로에서 관측된 도로 중심으로 **점진적 합류**합니다. 도로가 안 보이면 강제로 중앙 복귀하지 않습니다.
4. **1랩은 중앙 경로 추종 위주**입니다. 아웃–인–아웃 편향, 추월·우회 경로 생성 기능을 비활성화합니다. 장애물은 감속 또는 정지로 처리합니다. 코너 곡률 / 도로 폭 / 연석 거리 / 진행 방향 / 오도메트리 속도를 주행하며 축적합니다. 1랩 기록은 지도 파일이 아닌 **주행 중 센서 측정만** 사용합니다.
5. 1랩 완료는 카메라 횡단선 재검출 + 관측 도로형상 일치 + 충분한 이동 거리 + 누적 회전 등의 증거가 있어야 **잠정** 인정합니다. 신호등 또는 주행 거리만으로 2랩으로 넘어가지 않습니다. 한 바퀴를 실제로 못 돌았으면 2랩 모드로 진입하지 않습니다.
6. 2랩부터만 첫 바퀴 기록의 감속·코너 정보를 참조합니다. **직진 목표속도 12m/s**이며 경계 확인 거리, 곡률, 제동거리 제한은 계속 적용됩니다. 차량 모델 최대속도도 12m/s입니다.
7. 최초 목표 직진 **7m/s**, 코너 목표 **직진 목표의 30% (2.1m/s)**입니다. 이 또한 가시거리와 횡가속도 조건에 따라 낮아집니다.
8. **20m/s는 최종 설계 목표**로 기록만 남깁니다. 현 차량 모델은 12m/s 한계이며, 5m/s² 제동과 0.3초 인식 지연, 0.55m 여유 기준 20m/s에는 최소 약 46.55m의 검증된 정지 가능 전방 경로가 필요합니다. 현 로컬 도로 검증 범위는 길어야 약 7m라 활성화하지 않았습니다.

## 새 로그 항목

- `startup_s=`: 움직이는 시간 기준 초기 우측 연석 추종 누적 시간
- `right_ref=`: 출발 직후 관찰한 기준 우측 연석 거리
- `right_error=`: 현재 연석 거리와 기준 간격 차이
- `line_phase=GRID/CENTER`: 3초 유지 단계 / 중앙 합류 및 추종
- `passing=OFF`: 추월 및 우회 비활성화
- `track_points=`: 1랩 중 실제 관찰해 저장한 도로 형상 샘플 개수
- `odom_v=`: Gazebo 오도메트리 측정 속도. `v=`는 주행 명령/제어 속도
- `lap_check=`: 출발선 재검출에 대한 랩 판정 사유

## 설치 및 실행

```bash
# 기존 Gazebo 종료 후, 사용자 Downloads 폴더에 ZIP을 저장한 상태
unzip -o ~/Downloads/team01_f1_exploration_v9.zip -d ~/urrc_2/src/team_01
cd ~/urrc_2/src/team_01/team01_race
bash scripts/run_offline_tests.sh
bash scripts/run_local_monza.sh 2>&1 | tee ~/team01_v9.log
```

현재 작업 폴더 `~/urrc_2/src/team_01` 내부에 동일한 이름의 패키지를 가진 백업 디렉터리를 만들지 마십시오. `colcon`이 중복 패키지로 판단합니다.

## 학습 데이터

- `~/.local/state/urrc_team01/learning/active_lap1.json` : **10m 진행마다** 저장되는 진행 중 트랙 센서 관측 기록. 실행 전에 로딩하지 않으며 새 실행 시 덮어씁니다.
- `~/.local/state/urrc_team01/learning/lap1_*.json` : 출발선 및 안전 조건을 만족한 **잠정 완주** 기록. 실제 랩 인증이 아닙니다.
- 이 기록은 도로 폭, 기울기, 좌우 경계, 로컬 위치 적분 추정치입니다. 센서 오차·바퀴 미끄러짐으로 누적 오차가 발생할 수 있으며 루프 폐합 및 실측 기반 위치 추정 보정이 이후 필요합니다.

## 검사 범위

오프라인 단위 테스트와 합성 도로의 17m 단순화된 운동학 폐루프를 수행했습니다. **실제 ROS 2 / Gazebo 런타임, Monza 1랩 완주, 2랩 12m/s 실주행, 20m/s, 충돌 없음**을 인증하지 않습니다.
