# TEAM 01 v13 — 현재 안전한 경로 유지 및 완만한 조향

- **직선 구간:** 현재 차선에 장애물이 없고 연석 여유가 충분하면 측정된 현재 횡방향 위치를 유지합니다. 중앙선 추종을 강제하지 않습니다.
- **코너 또는 장애물:** 앞쪽 도로 곡률, 실제 차선에 놓인 장애물, 연석 위험이 확인되면 0m 오프셋(측정된 도로 중앙)으로 천천히 이동합니다. 목표 오프셋 변경은 **최대 0.28m/s**로 제한합니다.
- **정지한 전방 벽:** 넓은 LiDAR 벽에서 추정한 월드 정지 속도와 별도 센서의 도로 곡률이 함께 확인된 경우 코너 전조로 판단합니다. 정지한 물체 하나만으로 코너를 추론하지 않습니다.
- **조향:** 최대 증가율 35°/s, 실제 속도 5m/s 이상일 때 27°/s 및 시정수 0.16s 저역통과 평활화. 기존 차체 최대 조향 제한과 장애물·연석 검증 유지.
- **속도:** 현재 첫 랩 직선 8m/s 목표, 코너 시 30% 속도, 실제 센서 제한 우선. 새 센서로 25m 도로 경계를 검증했다는 의미는 아닙니다.
- **로그:** `recenter`, `hold_offset`, `front_wall_m`, `front_wall_world_v`, `steer`, `v`, `odom_v`.
- **상태:** 기존 회귀 111개와 신규 로직 7개를 포함한 118개 오프라인 테스트가 로컬에서 성공했습니다. Gazebo 실제 Monza 완주 검증과는 별개입니다.
