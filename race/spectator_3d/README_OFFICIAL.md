# URRC 공식 대회 3D 원격 관전

- 관전 전용: Gazebo 실행, 스폰, 출발, DNF, 판정 및 차량 제어를 수행하지 않습니다.
- 경기 진행 중 `bash race/spectator_3d/run_official.sh` 실행.
- 운영자 세션에서 맵과 단계 자동 인식, 현재 Gazebo의 GZ_PARTITION 공유.
- 동일 LAN의 브라우저에서 출력된 `관전 주소` 열기.
- 6개 맵과 TEAM01~12 명칭 대응. 브라우저의 3D 차량 형상은 시각화용 공통 템플릿입니다.
- 웹 FPS는 브라우저 렌더링 FPS이며 실제 Gazebo 카메라 영상 FPS가 아닙니다.
- 위치·속도·랩·순위는 관전용 잠정 추정치이며 공식 순위/판정에 사용하면 안 됩니다.
- 출발등은 공식 운영자의 RUNNING 상태로 출발 여부만 표시하며 실제 5등 점등 진행은 제공하지 않습니다.
- 인터넷에 공개하지 마세요. LAN 내부 사용, 접근 키 비공개, Gazebo 제어 포트 별도 차단.
